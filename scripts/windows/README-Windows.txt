========================================================================
  🐘 PostgreSQL DDL Studio - Windows Portable Edition
========================================================================

Gereksinimler:
- Windows 10 / Windows 11 (64-bit)
- Java 17 veya daha yenisi (https://adoptium.net/ adresinden indirebilirsiniz)

Nasıl Çalıştırılır:
1. "PostgreSQL-DDL-Studio.vbs" dosyasına çift tıklayarak penceresiz doğrudan başlatabilirsiniz.
2. veya "PostgreSQL-DDL-Studio.bat" dosyasına çift tıklayarak çalıştırabilirsiniz.
3. Komut satırından çalıştırmak için:
   java -jar PostgreSQL-DDL-Studio.jar -db:POSTGRESQL -od:./export_output -s:profiles.json

Özellikler:
- PostgreSQL Şema, Tablo, View, Fonksiyon ve İndeks DDL Dışa Aktarma
- Görsel İnteraktif ERD Şema Diyagramı
- Canlı Sunucu Durumu & Performans Metrikleri
- Evrensel Veritabanı & Docker Asistanı (Docker, Neon, Supabase, AWS RDS, vb.)
- Otomatik Şifrelenmiş Profil Yöneticisi (AES-256)
- Git & GitHub Senkronizasyonu
- SQL Arama & Kod Önizleme

Destek & İletişim:
https://github.com/DevranTheDeveloper/postgres_ddl_export_console_java
